# Инструкция по сборке и запуску
## Лабораторная работа №3 (MPI)

Данный документ описывает сборку и запуск MPI-версии умножения матриц из Лабораторной работы №3.

> **ВАЖНО:** Лабораторная работа №3 выполняется на суперкомпьютере. Она не входит в корневую сборку CMake (в `CMakeLists.txt` подключены только `lab_1`, `lab_2` и `lab_4`), поэтому локальная команда `cmake --preset windows-release` её не собирает. Компиляция выполняется непосредственно на суперкомпьютере с использованием MPI-компилятора из установленного на нём программного обеспечения.

---

## 1. Состав лабораторной работы

* `src/main.cpp` — MPI-программа умножения матриц (ленточная декомпозиция по строкам).
* `include/matrix.hpp` — класс `Matrix` и функция `Matrix::multiply_strip`.
* `scripts/superCompile.pbs` — скрипт SLURM для запуска серии бенчмарков.
* `scripts/BuildCharts.py` — построение графиков по результатам `results.csv`.

---

## 2. Требования к окружению суперкомпьютера

На суперкомпьютере должно быть установлено:

* MPI-окружение (в `scripts/superCompile.pbs` используется Intel MPI, модуль `intel/mpi4`);
* компилятор C++ с поддержкой стандарта C++17;
* система управления заданиями SLURM (`srun`, `sbatch`).

Конкретные имена модулей и MPI-компилятора определяются установленным на суперкомпьютере программным обеспечением. В примерах ниже используется Intel MPI; если на кластере доступен другой MPI, применяется соответствующий компилятор-обёртка (`mpiicpc`, `mpicxx` и т.п.).

---

## 3. Компиляция на суперкомпьютере

В репозитории Лабораторная работа №3 не подключена к корневой CMake-сборке, поэтому на суперкомпьютере она компилируется напрямую MPI-компилятором.

Все команды выполняются в каталоге `labs/lab_3` на суперкомпьютере:

```bash
cd labs/lab_3

# Загрузка MPI из установленного на суперкомпьютере ПО
module load intel/mpi4

# Компиляция
mpiicpc -O3 -std=c++17 -Iinclude src/main.cpp -o matMulMPI
```

В результате в каталоге `labs/lab_3` появится исполняемый файл `matMulMPI`.

> Если в системе используется другой MPI-компилятор, замените `mpiicpc` на доступный wrapper (например, `mpicxx`), не меняя остальные параметры сборки.

---

## 4. Запуск программы вручную

Запуск программы выполняется средствами планировщика задач, установленного на суперкомпьютере. Используйте команды вашего планировщика для выделения вычислительных ресурсов и запуска MPI-программы; их синтаксис определяется конфигурацией конкретного кластера.

Программа принимает один обязательный позиционный аргумент — размер квадратной матрицы `N`. Число MPI-процессов задаётся при запуске средствами планировщика и не должно превышать количество выделенных вычислительных ядер.

Программа выводит размер матрицы, число MPI-процессов, время выполнения в секундах и производительность в GFLOPS.

---

## 5. Запуск серии бенчмарков

Серия экспериментов запускается скриптом `scripts/superCompile.pbs`. Скрипт сам загружает модуль `intel/mpi4`, перебирает размеры матриц и число процессов, вызывает `srun` и сохраняет результаты в `scripts/results.csv`.

Скрипт ожидает исполняемый файл `matMulMPI` в своём текущем каталоге, поэтому перед запуском скопируйте его в `scripts`:

```bash
cd labs/lab_3
cp matMulMPI scripts/
cd scripts

sbatch superCompile.pbs
```

После завершения задания результаты будут записаны в `labs/lab_3/scripts/results.csv`, а вывод задания — в файл `slurm-<job_id>.out`.

---

## 6. Построение графиков

Графики строятся по файлу `scripts/results.csv`:

```bash
python3 labs/lab_3/scripts/BuildCharts.py
```

В каталоге `labs/lab_3/scripts/figures/` будут созданы:

* `mpi_time.svg` — время выполнения от размера матрицы для разного числа процессов;
* `mpi_gflops.svg` — производительность (GFLOPS) от размера матрицы;
* `mpi_speedup.svg` — ускорение в зависимости от `N` и числа процессов;
* `mpi_efficiency.svg` — эффективность распараллеливания.
