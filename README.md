# Курс «Параллельное программирование»

Репозиторий содержит лабораторные работы, посвященные последовательной реализации и параллельному ускорению трудоемких вычислительных задач с использованием различных технологий: **OpenMP**, **MPI** и **CUDA**.

---

##  Общая информация

* **Язык программирования:** C++
* **Система сборки:** CMake
* **Автоматизация и бенчмаркинг:** Python 3 
* **Целевая задача (Л/Р №1–4):** Перемножение квадратных матриц размерностью $N \times N$
